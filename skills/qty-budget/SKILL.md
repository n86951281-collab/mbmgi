# 數量計算書與預算書

規則以 CLAUDE.md 為準，本 SKILL 只講程式與步驟：
- 版面：「交付版面規則（通用）」的**範本優先**、「三、Excel 試算表」。
- 數量：「平縱橫斷面至挖填方、混凝土量作業流程」第 8～10 階段（平均斷面法、自然方、三層數量勾稽）。
- 單價、參數連動、圖數量勾稽、驗證：「工作方式規則」一～四。

`scripts/` 是 P33 東山街案（臺中市新社區東山街與協興街路口排水改善工程）的**參考實作**：工項、參數、單價、圖號、費率、工期、說明書內文都是 P33 的。新案把程式複製到案件資料夾後改參數與工項，不要直接拿 P33 數值交件。

## 環境
- Python 3.12＋openpyxl；執行前設 `PYTHONIOENCODING=utf-8`。程式不 import 同資料夾模組，可加 `-I`。
- Excel（COM）：重算、匯出 PDF、轉 PNG，只有裝 Excel 的機器能做。
- 案件資料夾放 `case_config.json`（格式見 `templates/case_config.example.json`）與輸入檔；程式用 `--case <案件資料夾>` 指定，省略時用程式所在資料夾。

## 步驟

### 1. 收輸入
- 標準圖：每公尺數量表（混凝土、墊層、模板）、鋼筋表（號數、間距、長度、支數）。新案先確認用哪一張標準圖與版次（CLAUDE.md 流程第 5 階段）。
- 斷面積：設計橫斷面圖的挖、填面積（`section-drawings` 或圖冊 X 圖產出），整理成上表欄位的 csv。
- 平面配置圖：各構造物長度、座數、拆除長度、編號（例 #A、#AC1）。
- 公司舊案範本（向使用者要；P33 用的見下方「範本來源」）：數量計算表 xlsx、PCCES 預算書 xls、封面、計畫說明書。

### 2. 範本先轉檔、讀格式
- xls 先用 Excel COM 另存 xlsx（`SaveAs(<新檔>, 51)`），NAS 原檔只讀，複製到暫存區再轉。
- 讀範本的字型、字級、列高、欄寬、合併儲存格、框線、頁面設定（縮放、邊界、頁首頁尾、重複列），**先 dump 成 UTF-8 文字檔**再讀，不要直接在主控台印中文：
  ```powershell
  # 例：Excel COM 逐格輸出 Text、Font.Name、Font.Size、RowHeight、ColumnWidth 到 txt
  $lines | Out-File -Encoding utf8 D:\Claude_工作區\暫存\範本格式.txt
  ```
- 照範本原樣套用（`budget_pcces.py` 的 `pc_head`、`pc_info`、`pc_page`、`drow` 是照象鼻段 PCCES 欄寬、字級、列高寫的），範本沒有的附表（單價依據、參數、假設與待確認）用同字型。

### 3. 工項清單核對表（列工項前逐項打勾）
| 類別 | 必查工項 |
|---|---|
| 拆除 | 既有構造物打除（長度、斷面、廢料運棄量）、AC 路面切割；逐項問使用者拆不拆 |
| 土方 | 構造物開挖、回填（材料：土／CLSM）、餘土處理（運距、收容費） |
| 結構 | 各強度混凝土（墊層、結構、緣石分列）、模板、鋼筋（**橫向主筋＋縱向配力筋＋搭接**，依 SD280W／SD420W 分列）、預製品（溝蓋板甲乙種）、集水井、人孔踏步、伸縮縫、與既有排水銜接 |
| 臨時設施 | **臨時擋土**（鋼軌樁、背插鐵板、材料搬運）、**臨時鋼管護欄**（設置位置問使用者）、**交通維持**（拒馬、交通錐、警示燈、標誌、旗手） |
| 路面 | AC 面層修復（寬度依道路挖掘許可） |
| 雜項 | 告示牌、擋排水、測量放樣、管線查證、試驗（混凝土、鋼筋）、工地清理、機具搬運 |
| 職安、環保 | 職安告示牌、職安人員、安全器材、教育訓練；環保宣導、車輛沖洗、灑水、清潔 |

每一項都要有圖號出處；圖上沒有的工項（例如 P33 的臨時鋼管護欄、縱向配力筋）要同時回饋繪圖補圖。

### 4. 數量計算書（`quantity_calc.py`）
1. 改 `PARAMS`（代號、名稱、數值或公式、單位、圖號出處）；工項 `Q` 用 `{代號}` 寫 Excel 公式，不貼死數值。
2. 土方：平均斷面法，兩端收尾方式（P33：最外集水井斷面外推半個井外寬 0.95 m）先問使用者。
3. 取整規則**全案選一種**，下游一律沿用：P33 工程數量計算表是「各構造物先 ROUND 到整數，再合計」，預算書數量讀 `qty_table_v*.json`。數量計算書（小數 2 位）與數量計算表（整數）並存時，在假設表註明以哪份為準。
4. 跑程式 → `quantity_calc_pdf.ps1` → `xlsx_preview.ps1`（見步驟 8）。

### 5. 配筋檢核（`rebar_check.py`，有需要才做）
- 只在引用的標準圖超出適用範圍時做（例：臺北市 B20 適用渠寬≦100 cm，P33 用 110 cm）。
- 改 `R` 表的材料、土壓、載重假設；地質資料缺時標【待確認】。
- 縱向配力筋（溫度及收縮鋼筋）要檢核並算每公尺重量（含定尺搭接增量），回填到數量計算書參數。
- 結果放檢核表，不上圖；圖上只留施工必要的鋼筋規格。

### 6. 工程數量計算表（`qty_table.py`）
- 依範本格式改寫 `big`／`item`／`sub`／`total`／`single` 呼叫；每列算式附「詳圖號」。
- 跑完確認 `qty_table_v*.json` 的總計與 xlsx 重算值一致（程式用同一算式在 Python 算一次）。

### 7. 預算書（`budget_pcces.py`）
1. **單價依據**（`SRC`，每列附出處）依序找：
   1. 公司同年度、同區舊案（P33：象鼻段 115 年 PCCES 預算書）
   2. 其他公司舊案或業主範例（P33：大湖範例 115 年）
   3. 推算（例：140／280 混凝土用 210 單價加減他市價差，SD420 用 SD280 乘價比），標【待確認】
   4. 他市單價 × 物價指數 K（P33：臺北市 112 年 × 115.6 月 119.16 ÷ 111 年 107.51），標【假設】
   - 不自行從範例金額反推費率；反推只用來核對。
   - 偏遠地區與一般地區單價分開（P33：象鼻段混凝土為偏遠地區價，不適用）。
2. **單價分析**（`analysis`）：工料明細分人、機、材、雜；訪價項目標【待確認訪價】。
3. **參數**工作表放費率：品管費率、利潤管理保險費率（P33 使用者指定 8%）、營業稅、空污費率、工程管理費（分段：500 萬以下 3%、500 萬～2,500 萬 1.5%、以上 1%，級距【待確認】）、委外設計、監造服務費。詳細表與總表都用公式引用。
4. **工期連動**：工期、旗手人數、工作天、職安人月、交維器材租期、計畫說明書「預定完工期限」要從同一參數算出。P33 v2.5 這幾項仍是寫死的數字（`TRAF` 旗手 120 工、壹.三.9 職安 3 人月、計畫說明書「90 日曆天」），新案要改成參數表儲存格加公式，改工期時一次連動。
5. 封面、計畫說明書照使用者給的範本；簽核職稱、會計科目、工程編號沒有資料就標【待補】。計畫說明書的經費直接用公式連到預算總表。
6. 跑程式 → 步驟 8 檢查。

### 8. 交付檢查（每份 xlsx 都做）
```powershell
$env:PYTHONIOENCODING='utf-8'
python -I <scripts>\budget_pcces.py --case <案件資料夾> --stamp (Get-Date -Format yyyyMMdd_HHmm)
& <scripts>\quantity_calc_pdf.ps1 -xlsx <輸出xlsx完整路徑> -dumpdir <暫存>     # 重算、存檔、PDF、掃 ### 與錯誤值
& <scripts>\xlsx_preview.ps1 -xlsx <輸出xlsx完整路徑> -outdir <暫存> -rows 40   # 每張工作表轉 PNG，逐張看
python -c "from pypdf import PdfReader; print(len(PdfReader(r'<輸出pdf>').pages))"  # 核頁數
```
- `Overflow/error cells` 要 0；不是 0 就加欄寬或改數字格式，重出。
- PNG 每張都看：文字截斷、列高不足、合併儲存格錯位。沒看過的頁，回報時明講。
- 檢查用的 txt、PNG 放暫存區，不放交付資料夾。
- 三層數量勾稽：數量計算書 ↔ 工程數量計算表 ↔ 預算詳細表數量，不一致逐項列出。

### 9. 回饋與版次
- 算數量發現圖面缺漏、圖與圖不一致（例：開挖寬 S-03 寫 210、S-01 是 190），列圖號與問題回饋繪圖，附檔名與版次；圖改完再核對新版。
- 內容有變就升版次（程式內 `VER`），不可只改存檔時間；存檔時間用 `Get-Date`。

## 踩過的雷（2026-11-06 P33 實測）
- `###` 是 Excel 重算後依實際值與欄寬才出現的，openpyxl 產檔時看不到；一定要 COM `CalculateFull` 後讀 `.Text` 掃。
- 列高是程式估的（固定列高，不用自動列高），估算要放寬：全形字寬約 2.15～2.3×pt/11、半形 1.15～1.2×pt/11，可用寬度扣 3～3.5；**標題列、欄名列也要估**（25 pt 換行標題曾被截掉）。
- `xlsx_preview.ps1` 轉出白圖：要先 `Activate` 工作表，`CopyPicture` 後延遲（1.5 秒）再 `Paste`。仍白就加大 `-delay` 重跑。
- COM 開含 `(臺中48)`、中文的路徑：先 `Resolve-Path -LiteralPath` 取完整路徑再給 `Workbooks.Open`；不要用相對路徑或萬用字元。
- 範本格式先 dump 成 UTF-8 txt 再用 Read 讀；PowerShell 主控台直接印中文會亂碼。
- PowerShell `Out-File -Encoding utf8` 會加 BOM；程式讀 json 一律用 `encoding="utf-8-sig"`。
- Python 字串裡的換行寫 `\n` 或 `chr(10)`，不要在字串常值裡直接斷行（曾讓產生器出錯）。
- 改 `.py` 用 Edit 工具；用 PowerShell `Set-Content`／`-replace` 改會把中文弄亂。
- 工程管理費是分段計算，不是單一費率乘總額；品管費、空污費率可用範例金額回算核對，但不可從範例反推利潤管理保險費率（P33 反推出 11.442%、23.9%，都不對，最後由使用者指定 8%）。
- `budget.py --qty` 讀的是 Excel 重算值（`data_only=True`），數量計算書要先經 `quantity_calc_pdf.ps1` 存檔過，否則讀到空值。
- 數量計算書（小數 2 位）和工程數量計算表（各構造物取整）總計會差小數；預算書要明定讀哪一份。
