# 鋼筋混凝土溝體斷面配筋檢核

本 SKILL 只講**方法與步驟**，不附程式。計算程式用 `qty-budget` 的 `rebar_check.py`、`rebar_check_pdf.ps1`、`xlsx_preview.ps1`（安裝後在 `~/.claude/skills/qty-budget/scripts/`，倉庫內 `skills/qty-budget/scripts/`）。

規則以 CLAUDE.md 為準，這裡只引用不重抄：
- 「工作方式規則」一：標準圖超出適用範圍時，不可只按比例放大交圖，要明講「未經結構檢核」並排入配筋檢核；依記憶引用的規範條號標【待確認】。
- 「設計圖冊版面與標註規則 v2」共通第 4 點：圖面不放檢核說明；鋼筋材料規格（例如 D16、D19 用 SD420W）留在圖上。
- 「三、Excel 試算表」：字級、配色、凍結、頁首頁尾、保留公式、出處、檔名版次、附 PDF。
- 「工作方式規則」二～四：圖、數量、檢核表互相勾稽；內容有變就升版；交付前用最終格式目視。

`rebar_check.py` 是 P33 東山街案（箱涵式側溝 W×H＝110×100 cm，引用臺北市 B20）的**參考實作**：構件、鋼筋配置、載重模型、材料、出處說明都是 P33 的。新案照下方「為新斷面改參數」改，不要直接拿 P33 結果交件。

## 什麼時候做
| 情境 | 做法 |
|---|---|
| 引用的標準圖超出適用範圍（例：臺北市 B20 附註「配筋適用於渠寬 100 cm 以下」，P33 用 110 cm） | 必做。檢核前圖上不得寫成定案配筋；回報時明講「配筋未經結構檢核」 |
| 使用者問「配筋有沒有算」「鋼筋號數間距跟原圖一樣嗎」 | 先查有沒有檢核表；沒有就照實回答「沒有重算，沿用原圖」，再排入檢核 |
| 自繪溝體標準圖（沒有他機關標準圖可引用） | 必做，檢核表與標準圖同版交付 |
| 標準圖在適用範圍內、尺寸與載重條件相符 | 不必做，數量計算書註明引用的標準圖圖號與版次 |

不可只按比例放大鋼筋長度就交圖。P33 第一次就是這樣（號數、間距沿用 W100），使用者追問後才補檢核。

## 1. 收輸入（缺項就問，不自行假設）
輸入欄位與 P33 範例值見 `templates/rc_input.example.json`。

| 類別 | 項目 | 來源 | P33 值 |
|---|---|---|---|
| 斷面 | 內寬 W、內高 H、側牆厚、底版厚、頂版或蓋板厚、加腋尺寸 | 本案設計圖（S-01） | 110×100 cm、牆 20、底版 20、預鑄蓋板 23；加腋未計入檢核 |
| 頂部型式 | 預鑄蓋板（簡支）／場鑄頂版（剛構）／開口 U 溝 | 本案設計圖 | 預鑄甲、乙種蓋板，每塊沿溝向 100 cm，甲種格柵開口 73 cm |
| 覆土與鋪面 | 覆土深、鋪面種類與厚度 | 道路斷面、挖掘許可 | 蓋板即路面，AC 5 cm |
| 車輛載重 | 載重模型（HS20-44、HS15 等，依業主或道路主管機關規定）、衝擊係數、分布寬 | 業主規定、公路橋梁設計規範 | HS20-44 後輪 7.26 t |
| 土壓 | 靜止土壓係數 K0、土單位重 γ、交通超載等值土高 | 地質調查報告 | K0＝0.5、γ＝1.9 t/m³【待確認，無地質資料】；超載 0.6 m |
| 地下水 | 地下水位、是否計浮力與水壓 | 地質調查報告 | 未計【待確認】 |
| 材料 | fc'（溝體、蓋板分列）、fy（依號數 SD280W／SD420W 分列） | 標準圖附註、本案一般說明 | 溝體 210、蓋板 280；D16、D19 用 SD420W，D10、D13 用 SD280W（B20 未註明，經使用者確認） |
| 保護層 | 接土面、內面、蓋板 | 標準圖附註、規範 | 蓋板 3 cm、接土面 5 cm、底版 4 cm |
| 現有配筋 | 各構件主筋、箍筋、配力筋的號數、間距、支數 | 引用標準圖的鋼筋表 | B20 鋼筋表 ①④⑧⑩、A、B、E、F |
| 集水井 | 內寬、井壁厚、最大深度 | 本案設計圖 | 內寬 150 cm、深 1.6 m【待確認】 |

缺地質資料時，土壤參數用一般值並標【待確認】，結論寫明該參數對使用率的敏感度（P33 側牆使用率 14%，土壓參數差很多也不影響結論）。

## 2. 檢核項目
每列都要有「公式（引用上方符號儲存格）、單位、出處」。規範與條號依記憶引用者一律標【待確認】，交付前上規範原文核對。

### 2.1 載重與組合
- 載重組合：U＝1.2D＋1.6L＋1.6H（D 靜載重、L 活載重含衝擊、H 土壓）；出處「內政部 混凝土結構設計規範」載重組合章節【待確認版次與條號】。
- 強度折減：撓曲 φ＝0.90、剪力 φ＝0.75（同上規範【待確認條號】）。
- 車輛：輪重、衝擊 I＝15.24／(L＋38)≦0.30、主筋垂直車行之版分布寬 E＝1.22＋0.06S（m）；出處「交通部 公路橋梁設計規範」（AASHTO Standard 3.8、3.24 同）【待確認條號】。分布寬大於單塊蓋板寬時，輪重全由單塊承受。
- 土壓：靜止土壓 K0γz，加交通超載等值土高（AASHTO 3.20.3，2 ft≒0.6 m）【待確認】。
- 空箱與滿水、有無地下水，至少各檢討一種控制狀況；P33 只算空箱、無地下水（見「已知限制」）。

### 2.2 各構件
| 構件 | 力學模型（P33） | 檢核 |
|---|---|---|
| 預鑄蓋板（乙種，實心） | 簡支，跨徑＝W＋牆厚，輪重置跨中 | Mu／φMn；Vu（輪重距支承 d）／φ(Vc＋Vs)，原圖有箍筋就計入 |
| 預鑄蓋板（甲種，格柵開口） | 開口段由兩側肋承受，彎矩取同乙種 | 肋寬＝板寬－開口；Mu／φMn、Vu／φ(Vc＋Vs) |
| 側牆 | 懸臂（預鑄蓋板不提供頂部束制），梯形土壓＋超載 | Mu／φMn、Vu／φVc |
| 底版 | 均布地反力上推、兩牆線載重；輪重沿溝向 45° 擴散 | Mu／φMn、牆根 Vu／φVc、最小鋼筋 0.0018bh |
| 集水井井壁 | 水平四邊框架，角隅固接，Mu＝pL²／12 | Mu／φMn、Vu／φVc |
| 場鑄頂版箱涵 | 閉合剛構（P33 未用，`rebar_check.py` 沒有此模型） | 另建模型或用結構軟體，結果貼入檢核表並附出處 |

公式要點：a＝As·fy／(0.85fc'·b)；φMn＝φ·As·fy·(d－a／2)；Vc＝0.53√fc'·b·d（kgf、cm）；Vs＝Av·fy·d／s。

### 2.3 鋼筋量與配置
- 主筋：依 Mu 求需要 As，與現有配置比較；用使用率表示（Mu／φMn）。
- 配力筋（溫度及收縮鋼筋，沿溝向）：側牆最少水平鋼筋比 ρh（D16 以下、fy＜4200 取 0.0025）、底版溫度鋼筋比 ρt（fy 2800 取 0.0020）【待確認條號】；間距上限牆 min(3t, 45 cm)、版 min(5t, 45 cm)。P33 原 B20 鋼筋表沒有縱向筋，是數量計算時才發現補配（D13@25 內外兩層）。
- 最小鋼筋比：版 0.0018bh；主筋也要比較，不只算出來不比。
- 裂縫控制與間距：主筋間距上限、裂縫控制（規範「撓曲構材鋼筋分布」相關條文【待確認】）。P33 只檢核了配力筋間距，主筋裂縫控制未檢核，新案要補或在結論列「未檢核」。
- 錨定與搭接：受拉搭接長度依規範計算（P33 以 40db＝52 cm 假設【待確認】）；錨定長度 P33 未檢核。
- 每公尺鋼筋重量：每斷面支數×單位重×定尺搭接增量係數（12 m 定尺：1＋搭接長／12），P33 側溝縱向筋 E＝30 支×0.994 kg/m×(1＋0.52／12)＝31.11 kg/m。依 SD280W／SD420W 分列。

### 2.4 結論
- 結論區每構件一列：構件、檢核項、使用率（顯示百分比）、OK／NG（`=IF(比值<=1,"OK（使用率 xx%）","NG，需加筋")`）。
- 結論區另列「未檢核項目」（例：P33 集水井格柵蓋、錨定長度、裂縫控制），不可省略。
- 前提條件要寫進結論：例如「D19 若只用 SD280W，甲種蓋板彎矩使用率變 106%，NG」。這類條件會變成圖上的材料規格。

## 3. 用 `rebar_check.py` 跑檢核
`rebar_check.py` 把每列寫成 `(項次, 項目, 符號, 數值或公式, 單位, 說明／出處)`，公式用 `{符號}` 引用前面列，產檔時換成儲存格位址，所以 Excel 保留公式。

### 3.1 為新斷面改參數
1. 案件資料夾放 `case_config.json`（格式見 `qty-budget/templates/case_config.example.json`，用到 `out_dir`、`file_prefix`、`title_block.project`）與斷面尺寸 json（`--param`，預設 `design_param_v1.json`，單位 m；程式只讀 `W`、`H`、`t_wall`、`t_slab`、`t_cover`、`well_in`）。
2. 把 `rebar_check.py` 複製到案件資料夾再改，不改倉庫原檔。
3. 改 `R` 表：
   - 第 1 節：材料、單位重、K0、γ、超載、輪重；每列「說明／出處」改成本案依據，假設值標【待確認】。
   - 第 2～6 節：鋼筋支數、號數、間距、保護層、甲種蓋板開口寬、集水井深度，改成本案引用標準圖的鋼筋表；說明欄的圖號（S-01、B20 鋼筋表編號）同步改。
   - 需要的號數面積（例 D10、D22）在第 1 節加列，不要在公式裡寫死數字。
   - 構件不同（例如場鑄頂版、無蓋 U 溝）時，整節改寫或刪除，`CHECKS` 同步增刪。
4. 改 `CHECKS`（結論區列哪些比值）。
5. 改輸出檔名：程式內寫死 `_箱涵式側溝配筋檢核表_W110_v1.2.xlsx`，改成本案尺寸與版次；頁首「箱涵式側溝配筋檢核」視構造物改。
6. 改完先把 P33 參數代回去跑一次，確認結果與 P33 v1.2 一致（蓋板彎矩 54%／77%、側牆 14%、底版 41%、縱向筋 49%／39%），再換本案參數。

### 3.2 執行與交付檢查
```powershell
$env:PYTHONIOENCODING='utf-8'
python -I <案件資料夾>\rebar_check.py --case <案件資料夾> --param design_param_v1.json --stamp (Get-Date -Format yyyyMMdd_HHmm)
$s = "$HOME\.claude\skills\qty-budget\scripts"
& "$s\rebar_check_pdf.ps1" -xlsx <輸出xlsx完整路徑> -dumpdir <暫存>          # COM 重算、存檔、匯出 PDF、掃 ### 與錯誤值
& "$s\xlsx_preview.ps1" -xlsx <輸出xlsx完整路徑> -outdir <暫存> -rows 140   # 轉 PNG 目視
python -c "from pypdf import PdfReader; print(len(PdfReader(r'<輸出pdf>').pages))"
```
- `Overflow/error cells` 要 0；不是 0 就調欄寬或數字格式（例：ρ 值用 `0.0000`，P33 曾顯示成 0.00），升版重出。
- 讀 `-dumpdir` 的 values txt 核對每個比值與結論文字；不要只看程式印出的路徑。
- 紙張用 A4 橫式（P33 用 A4 直式時被縮到 14 pt 以下，改橫式後 8 頁）。PNG、PDF 每頁看過；沒看的頁回報時明講。
- 檢查用 txt、PNG 放暫存區，不放交付資料夾。輸出檔已存在時程式不覆蓋，重出要換存檔時間；內容有變要升版次。

## 4. 結果回饋
- **結果不上圖**：檢核結果（OK、使用率、「經檢核」字樣）只放檢核表。P33 曾把「經配筋檢核表 v1.1 檢核 OK」寫進 S-01 註記，使用者要求全冊刪除。
- **材料規格留圖上**：檢核前提（例：D16、D19 用 SD420W，D10、D13 用 SD280W）寫在標準圖註記。
- **原圖的「待確認」註記**：檢核 OK 後，刪掉「施工前結構檢核【待確認】」這類字樣，換成材料規格；不要換成檢核說明。
- **NG**：列出構件、使用率、建議改法（加大號數、縮間距、加厚），交繪圖對話改斷面或配筋（附檢核表檔名與版次）；圖改完再用新圖數值重跑，檢核表與標準圖都升版。
- **新增鋼筋**（例 P33 縱向配力筋 E）：同時回饋繪圖（剖面標編號圈、鋼筋表加列、每公尺數量表拆列）與數量（每公尺重量）。同一張圖已有相同代號時改稱「側溝 E」「集水井 E」區分。
- **每公尺鋼筋重量**：回填 `qty-budget` 數量計算書參數表（附檢核表檔名、版次、項次），依 SD280W／SD420W 分列；三方（檢核表、S-01 每公尺數量表、數量計算書）數值一致才算完成。

## 已知限制
### `rebar_check.py`（不改 qty-budget，新案在案件資料夾的複本裡改）
- **斷面型式寫死**：只有「預鑄蓋板＋懸臂側牆＋底版＋集水井」；沒有場鑄頂版剛構箱涵、無蓋 U 溝（側牆頂自由、無蓋板）的模型。
- **加腋、覆土未計**：蓋板直接當路面（AC 5 cm、單位重 2.3 寫在公式裡），沒有覆土深度輸入；加腋不計入斷面與有效深度。
- **地下水、水壓、浮力未計**；只有一組載重組合（1.2D＋1.6L＋1.6H），沒有滿水、0.9D 等控制狀況。
- **材料與載重寫在 `R` 表**：fc'、fy、γ、K0、超載、輪重、衝擊公式、分布寬公式不從 json 讀；json 只讀 6 個尺寸。
- **鋼筋配置寫死為 B20**：支數（⑩ 7 支、① 4 支）、間距（@15、@7.5、@25）、號數面積只有 D13／D16／D19、D13 單位重 0.994 kg/m、甲種蓋板開口 73 cm、緣石 0.2×0.15 m。
- **幾何寫死**：保護層（蓋板 3、牆 5、底版 4 cm）；縱向筋路徑長 2(H＋10)＋(W＋30)、2H＋(W＋10) 是 P33 S-01 A、B 筋形狀；集水井深 1.6 m、井壁厚用側牆厚 `t_wall`（不讀 `well_wall`）。
- **最小鋼筋只算不比**：5.16 算出底版 Amin，但沒有列入 `CHECKS`，結論不會出 NG；主筋最小鋼筋比、主筋間距、裂縫控制、錨定長度都沒有檢核。
- **搭接**：40db＝52 cm、12 m 定尺是假設值，不是依規範公式（fc'、fy、位置係數）算的。
- **輸出檔名與版次寫死**（`箱涵式側溝配筋檢核表_W110_v1.2`），頁首文字寫死「箱涵式側溝配筋檢核」；檔案已存在就停止。
- `rebar_check_pdf.ps1` 只輸出第 1 張工作表的 A～D、F 欄到檢查 txt；多工作表時要另外看。

### 方法本身
- 簡化模型（簡支蓋板、懸臂側牆、地反力均布），不是有限元素或剛構分析；側牆與底版的彎矩分配沒有考慮角隅連續。
- 剪力：依規範按彎矩設計之版可免檢剪力（AASHTO 3.24.4 同）【待確認】，P33 仍列出供參。

## 【待確認】
- 規範版本與條號：內政部「混凝土結構設計規範」（版次、載重組合、φ、ρmin、溫度鋼筋、牆最少水平鋼筋、搭接長度條號）、交通部「公路橋梁設計規範」（HS20-44、衝擊、分布寬條號）；目前依記憶引用。
- 載重模型：業主是否指定 HS20-44 或其他（含是否採用 AASHTO LRFD 的 HL-93）。
